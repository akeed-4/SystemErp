ما الذي يحدث عند النقر؟

1. إنشاء ملف UBL 2.1 XML متوافق مع اشتراطات الهيئة.

2. توليد التشفير الرقمي والهاش SHA-256 وربطه بالفاتورة السابقة (PIH Chain).

3. إرسال طلب HTTP POST آمن إلى بوابة ZATCA لمحاكاة الاعتماد والتصريح الفوري (Clearance / Reporting).
