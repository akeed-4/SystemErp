أوامر سطر الأوامر (CLI Commands for .NET 9) Terminal 
# 1. الانتقال إلى مجلد الباك إند
cd backend

# 2. استرجاع حزم NuGet لجميع المشاريع في الـ Solution
dotnet restore

# 3. بناء المشروع والتأكد من خلوه من الأخطاء
dotnet build

# 4. تشغيل خادم الـ Web API على المنفذ الافتراضي
dotnet run --project src/RayahAccounting.WebApi

# 5. تشغيل واجهة توثيق Swagger في المتصفح:
# http://localhost:5000/swagger
